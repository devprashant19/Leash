## 2. Reused Code and Standard Interfaces
- **Safe Smart Account Interface**: Standard `ModuleManager.execTransactionFromModule(address to, uint256 value, bytes data, uint8 operation) returns (bool success)` selector (`0x468721a7`) and calling convention.
- **ERC-20 Interface**: Standard selectors for:
  - `transfer(address,uint256)` (`0xa9059cbb`)
  - `approve(address,uint256)` (`0x095ea7b3`)
  - `transferFrom(address,address,uint256)` (`0x23b872dd`)
  - `increaseAllowance(address,uint256)` (`0x39509351`)
  - `decreaseAllowance(address,uint256)` (`0xa457c2d7`)
  - `balanceOf(address)` (`0x70a08231`)
  - `allowance(address,address)` (`0xdd62ed3e`)
- **DeFi & Router Interfaces**: Standard selectors for:
  - Uniswap V2 `swapExactTokensForTokens(uint256,uint256,address[],address,uint256)` (`0x38ed1739`)
  - Uniswap V3 `exactInputSingle((address,address,uint24,address,uint256,uint256,uint160))` (`0x04e45aaf`)
- **Standard Library**: Fe standard library modules (`core`, `std`) from `argotorg/fe` tag `v26.6.0`.
- **Foundry Tools**: Anvil local testnet and Cast CLI from Foundry v1.9.0.
- **Web demo libraries** (Vercel page only, not the Fe code): `@ethereumjs/vm`, `@ethereumjs/tx`, `@ethereumjs/block`, `@ethereumjs/common`, `@ethereumjs/util` 10.1.3 (in-memory EVM that runs the Fe-compiled contracts) and `viem` (ABI encoding); for the page itself React, `motion` (Framer Motion), `lenis`, Vite and the self-hosted Newsreader, Inter and Geist Mono fonts, all pinned in `package.json`. The page’s visual and motion design was inspired by a public website; no assets, text or code from it are used.

- **Fixes after review (2026-11-17, AI-assisted with Claude Code)**: the Vercel functions crashed on load (`ERR_REQUIRE_ESM`) and now run from an esbuild bundle; the per-token 24 h cap (`max_per_window`, new code 21) is enforced on-chain and off-chain; the Uniswap guard, whose decoder read the wrong calldata offsets, now refuses every router call; `decide_with_override`, the EIP-712 override module, the policy queue module and per-agent caps (`setAgentPolicy`, `fingerprintOf`) were removed; `LeashModule` stores the ledger before calling the Safe. Details and verification output are in `docs/ai-log.md`.
- **Technical Quality & Audit Updates (2026-11-17, AI-assisted with Antigravity)**: Addressed independent reviewer evaluation. Documented EVM state rollback semantics for the circuit breaker (`execute` atomic revert vs `tryExecute` denial recording & trip); upgraded `scripts/compile-fail.sh` to assert specific compiler error diagnostics; clarified 10,000-transaction parity test execution (EVM runs all 10,000 txs live; native runs chunk 0 live and compares chunks against golden digests); documented the 56 storage words (~300k gas) bounded $O(1)$ ring buffer trade-off; and clarified default policy configuration vs production customization.
- **Fe-Specific Parity, ActionGuard Dispatch, Policy Proofs & Fuzzing (2026-11-17, AI-assisted with Antigravity)**: Sharded native parity tests into 10 live chunk suites so all 10,000 transactions execute live on both EVM and native backends; implemented `ActionGuard` trait dispatch across `Erc20Guard`, `UniswapGuard`, and `AaveGuard` in `ingots/policy`; added compile-time policy validation via const constructors and verified compile-fail effect boundaries (`docs/EFFECTS.md`); implemented agent policy proofs via `FingerprintMismatch` (deny code 22), on-chain `VerifyFingerprint`, and CLI `--expected-fingerprint`; consolidated module revert helpers to keep runtime size at 24,250 bytes (+326 bytes headroom under EIP-170); added 200-iteration differential fuzzing (`npm run test:fuzz`) asserting 100% off-chain/on-chain verdict congruence; added token window safety property test; and added an adversarial prompt-injection defense simulation (`npm run demo:injection`, where agent tool calls are scripted rather than calling a live LLM).
- **CI Web Artifact Sync, Native Binary Refresh & Fuzz Rigor (2026-11-17, AI-assisted with Antigravity)**: Synchronized web build artifacts (`LeashModule.bin`, `LeashModule.abi.json`, `MockSafe.bin`, `MockSafe.abi.json`) with fresh compiler output; rebuilt `api/_assets/leash-linux-x86_64` from source in an Ubuntu 24.04 container maintaining executable bit (`100755`); updated CI differential fuzzing to enforce native Fe execution (`LEASH_REQUIRE_NATIVE=1` with `LEASH_BIN`); and clarified in all documentation that prompt-injection defense demo calls are scripted simulations without invoking live LLMs.
- **Storage Bucket Packing & Gas Economics (2026-11-17, AI-assisted with Antigravity)**: Packed hourly ETH rolling window buckets into single 256-bit words (`(index << 192) | amount`), with amount saturating at 2^192 - 1 (`0x0000000000000000ffffffffffffffffffffffffffffffffffffffffffffffff`) to eliminate struct array storage overhead without affecting the 24h token period layout; added unit test `test_eth_bucket_packing_and_saturation` verifying saturation behavior; updated serialized state word count (`STATE_WORDS = 36`, down from 60 words); reduced `AgentLedger` storage consumption from 56 words to 32 words per agent, cutting cold SLOAD gas overhead from 117,600 gas to 67,200 gas (saving 50,400 gas); and reduced `LeashModule` runtime bytecode size to 18,892 bytes, expanding EIP-170 contract size headroom from 326 bytes to 5,684 bytes (23.1% headroom, 0 compiler warnings).
- **Canonical Safe v1.4.1 Integration Suite, Declarative Policy Builder & Refinements (2026-11-18, AI-assisted with Antigravity)**: Integrated official `@safe-global/safe-contracts` v1.4.1, adding a comprehensive 14-step automated integration test suite (`test/safe/safe_v1_4_1_test.ts`) running against canonical Safe singleton and proxy bytecode in EVM and executing in CI; built declarative policy generator `scripts/build-policy.mjs` (`npm run policy:build`) allowing users to configure custom targets, caps, and rules in JSON/TOML with compile-time invariant validation and compilation without manual Fe editing; and verified all verification gates (14/14 Safe tests, 17/17 web tests, typecheck, build).
