## How to refresh the bundled CLI
Build on x86-64 Linux (`fe build --backend native`, copy `out/cli` to `api/_assets/leash-linux-x86_64`) or download the `leash-linux-x86_64` artifact from the CI `web` job. CI checks the bundled binary's fingerprint and version against a fresh build and runs the web tests with it.
