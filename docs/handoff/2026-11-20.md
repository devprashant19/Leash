# Handoff Note — 2026-11-20 (Phase 3 Complete)

## 1. What Was Done
- **Phase 3: Native CLI (`leash`) & C Library Complete**:
  - Implemented command-line argument dispatcher in `ingots/cli/src/lib.fe`:
    - Dispatches `check`, `explain`, `fingerprint`, `replay`, `--help`, `--version`.
    - Enforced static effect least-privilege: only `replay` receives `Fs`; `check` has zero filesystem access; `explain` and `fingerprint` declare `out: mut Stdout` only.
  - Implemented robust argument parser in `ingots/cli/src/args.fe`:
    - `--to`: 20-byte hex validation with `parse_hex_uint`.
    - `--value`: decimal ETH parsed with `UFixed<18>::parse`.
    - `--value-wei`: alternative integer wei parsing. Rejects conflicting `--value` + `--value-wei`.
    - `--data`: arbitrary hex decoding into `Calldata`.
    - `--op`: validates `call` or `delegatecall`.
    - `--now`: unix timestamp enforcement.
    - `--state`: canonical state deserialization via `policy::decode_state_bytes`.
    - Unknown flags and bad inputs safely report error on stderr and exit with code 1.
  - Implemented `leash check` in `ingots/cli/src/check.fe`:
    - Pure bridge to `policy::decide`.
    - Prints `ALLOW` (exit 0) or `DENY <ReasonName>: <msg>` (exit 2).
  - Implemented `leash explain` in `ingots/cli/src/explain.fe`:
    - Prints human-readable policy summary with exact limits and contracts.
  - Implemented `leash fingerprint` in `ingots/cli/src/fingerprint.fe`:
    - Outputs identical 32-byte Keccak-256 digest `0x3efcfc58aec5d1e7e81b5bded7820ed3ed8a0e654cf4aff3bfb793a7494ae6ee` matching `LeashModule.Fingerprint`.
  - Implemented `leash replay` in `ingots/cli/src/replay.fe`:
    - Parses CSV transaction history (`timestamp,to,value,data,op`).
    - Enforces monotonically non-decreasing timestamps.
    - Simulates transactions against rolling ledger, outputs per-row verdicts, and prints sorted reason breakdown and counts.
  - Built comprehensive golden test suite in `test/cli/golden/` (14 cases) and test runner `scripts/golden.sh`.
  - Built fixture parity test runner `scripts/fixtures-to-golden.sh` asserting identical verdicts between EVM policy tests and CLI predictions.
  - Provided C FFI header `examples/c/leash.h` and sample `examples/c/main.c`.
  - Updated `README.md` and `docs/ARCHITECTURE.md`.
  - All test suites green: 66 tests passing on `fe test`.
