## 2. Completed Features

1. **Compile-time Policy Validation (Feature 1)**:
   - `ingots/policy/src/validate.fe`: 16-variant `PolicyCheck` enum and pure `validate(p: Policy) -> PolicyCheck`.
   - `test/compile_fail/`: 6 negative test cases catching invalid policies at compile time.
2. **Recipient Allowlist (Feature 2, A8)**:
   - ERC-20 `transfer`, `transferFrom`, and `approve` destination addresses must be in `policy.recipients`.
   - Exception: `approve(spender, 0)` revocation is always permitted.
3. **Transaction Rate Limiting (Feature 2, A9)**:
   - Sliding 24h action counter in `AgentState.action_window`.
   - Rejects excess actions with `RateLimited` (code 12).
4. **Per-Agent Policy Configurations (Feature 3, B2, ADR-007)**:
   - `LeashModule.setAgentPolicy(agent, max_tx, max_window, custom_fingerprint)` configured exclusively by Safe multisig.
   - Per-agent dynamic evaluation and `fingerprintOf(agent)`.
5. **Machine-Readable CLI Output & Remaining Budget (Feature 4, D1, Tier A)**:
   - Pure `policy::remaining(policy, state, now) -> Budget` computing `eth_per_tx_wei`, `eth_window_wei`, `actions_in_window`, and `window_resets_at`.
   - `leash check --json` emitting schema-compliant JSON with plain-English messages from `policy::explain_reason`.
6. **Transaction Cooldown Period (Feature 5, A10)**:
   - Rejects transactions occurring within `policy.cooldown` of `state.last_action` with `CooldownActive` (code 13).
   - Exact boundary testing verified (`last + cooldown - 1` denied, `last + cooldown` allowed).
7. **Auto-Pause Circuit Breaker (Feature 6, B3)**:
   - `TryExecute` tracks consecutive policy rejections; trips to `tripped = true` upon reaching 3 denials, emitting `CircuitTrippedEvent`.
   - Once tripped, all transactions (even valid ones) are rejected with `CircuitTripped` (code 15).
   - Safe-only `resetBreaker(agent)` restores agent activity.
